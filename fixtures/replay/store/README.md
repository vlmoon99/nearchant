# Content-store demo fixture (`make demo`)

Recorded from one live run (NEAR AI TEE text + vision, Comfy Cloud Qwen-Image-Edit 2511 pictures) by
`apps/worker/dist/content-cli.js` with `RECORD_DIR` set. `photos/` are product photos generated for this demo
(Qwen-Image 2512 on Comfy Cloud, ours). `*.json` at the top are recorded model envelopes keyed by request;
`images/` the post pictures; `search/` web results (empty when search was unavailable).
